How it works

Three parts, joined by plain files.

1

A Claude Code plugin

Notes each chat's state in a small file.

2

Mochi Desktop

Reads the files and draws the state.

3

Mochi Studio

Paints her look. She updates at once.

Install

Set her up in three steps.

  1. Install the Xcode command line tools

    Mochi builds from source, so this is required.

    xcode-select --install

  2. Clone the repository and let Claude set it up

    Open Claude Code in the folder and say:

    Follow CLAUDE-SETUP.md in this folder to set up Mochi.

  3. Allow notifications

    Mochi appears in the bottom-right corner of the screen. Allow notifications when macOS asks.

Needs macOS 13+, Claude Code 2.1+ and the Xcode command line tools. Not notarised yet, so macOS may warn on first open.
