## How to capture

- Grant Screen Recording to the terminal in System Settings, then run `screencapture -x -o media/screenshots/<name>.png` (`-o` leaves out the shadow).
- Use a test chat or a neutral project name. Redact chat names, usage numbers, and personal paths before exporting.
- Export at 2× and keep PNGs under about 1 MB. Save them as `media/screenshots/01-working.png` and so on, in the order above.

When the captures are in, add them to the table in [media/README.md](../README.md).
